OGraf Developer Documentation for DaVinci Resolve
==================================================

OGraf is an EBU (European Broadcasting Union) open standard for web-based
broadcast graphics. It defines how HTML/CSS/JavaScript graphics are packaged,
described, and controlled by playout systems.

DaVinci Resolve supports OGraf graphics as Titles in the Edit page. Graphics
are rendered via Chromium Embedded Framework (CEF) through Fusion's OGrafLoader.

Official specification: https://github.com/ebu/ograf/tree/main/v1
JSON Schema:            https://ograf.ebu.io/v1/specification/json-schemas/graphics/schema.json


Quick Start
-----------

1. Copy an example from Examples/ as your starting point.

2. Edit the .ograf.json manifest:
   - Set a unique "id" and "name"
   - Define your parameters in "schema.properties"
   - Set duration in the "v_bmd" object (e.g., "v_bmd": { "duration": 5 })
   - IMPORTANT: Set "supportsNonRealTime": true (required for Resolve)

3. Implement your Web Component in the .js file:
   - Extend HTMLElement, use Shadow DOM
   - Implement all 8 required methods (see 03-Web-Component-API.md)
   - Key method: goToTime() for frame-by-frame seeking

4. Package for distribution:
   - Development: place raw files in Resolve's template directory
   - Distribution: package as .drfx bundle
   - See 06-Packaging-and-Installation.md for details

5. Install in Resolve (no admin user required):
   Per-user:
   - macOS: ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/
            Fusion/Templates/Edit/Titles/OGraf/
   - Windows: %APPDATA%\Blackmagic Design\DaVinci Resolve\Support\
              Fusion\Templates\Edit\Titles\OGraf\

   System-wide:
   - macOS: /Library/Application Support/Blackmagic Design/DaVinci Resolve/
            Fusion/Templates/Edit/Titles/OGraf/
   - Windows: C:\ProgramData\Blackmagic Design\DaVinci Resolve\
              Fusion\Templates\Edit\Titles\OGraf\
